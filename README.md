## 🛠️ Tech Stack
- **Frontend Framework:** React 19 + TypeScript
- **Styling:** Tailwind CSS (v4) with CSS Variables & Glassmorphism
- **Animations:** Framer Motion, react-type-animation, react-parallax-tilt
- **Background Effects:** @tsparticles/react, @tsparticles/slim
- **Icons:** React Icons (`react-icons/fi`, `react-icons/si`, `react-icons/fa`, `react-icons/tb`, `react-icons/hi`)
- **SEO & Meta:** react-helmet-async, sitemap.xml, robots.txt
- **Bundler & Tooling:** Vite 8

---

## ✨ Features
- 🌓 **Dynamic Dark & Light Theme**: Seamless switching with persistent state and dynamic GitHub stats theme synchronization.
- 🏝️ **Floating Island Dock Navigation**: Centered rounded-full navigation bar with interactive pill buttons for every section.
- 🤖 **Hero Section**: Typwriter animation, floating badges, and quick social links.
- 👤 **About Section**: Highlighting education, experience, career objectives, and live metric counters.
- ⚡ **Technical Skills**: Structured category tiles with authentic brand colors and official technology logos.
- 📁 **Featured Projects**: Filterable cards (All, AI/ML, Full Stack, Web) with 3D tilt effects, live demo, and GitHub links.
- 💼 **Experience & Education Timeline**: Responsive vertical timeline layout with clean milestone badges.
- 🏆 **Credly Verified Certifications**: Displaying verified badges from Google Cloud, Cisco, and IBM with direct credential verification links.
- 📊 **Live GitHub Activity**: Real-time contribution graph, top languages, streak counter, and repo stats.
- ✉️ **Contact Form**: Glassmorphic form with direct email trigger and social connectivity cards.

## 💻 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/nagarajchittapur18-dev/Portfolio.git

# Navigate to project directory
cd Portfolio

# Install dependencies
npm install

# Run the local development server
npm run dev
```

### Production Build
```bash
npm run build
```
